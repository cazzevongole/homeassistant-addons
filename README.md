# Home Assistant Add-ons: ADHD Helper

## About

ADHD productivity tool as a Home Assistant add-on. Includes tasks, focus timer, daily planner, habit tracker, and notes.

## Add-ons provided

- **ADHD Helper**: Full-featured ADHD productivity app with PWA support.

## Installation

1. Add this repository URL to your Home Assistant Add-on Store:
   `https://github.com/cazzevongole/homeassistant-addons`
2. Install the "ADHD Helper" add-on.
3. Start the add-on.
4. Open via the sidebar or Ingress.
